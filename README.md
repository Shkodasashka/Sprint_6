Подготовлено 10 тестов, распределенных по сценариям на 2 файла:
1. Тесты (8 тестов на 8 вопросов/ответов, файл test_click_on_question_and_expect_him_answer_on_mane_page.py) выпадающего списка в разделе «Вопросы о важном» с проверкой нажатия на вопрос и появления соответствующего ему ответа на главной странице сервиса - test_click_on_question_and_expect_him_answer_on_mane_page.
2. Тесты заказа самоката (2 теста с разными точками входа, файл test_postive_flow_order_scooter.py) с проверкой всего флоу позитивного сценария (в соответствии со сценарием в задании) с двумя наборами данных и двумя точками входа(две кнопки заказать на галвной странице сервиса) - test_postive_flow_order_scooter.

Файл conftest.py - фикстура открытия и закрытия браузера Firefox с открытием главной странице сервиса и нажатием кнопки согласия с использованием куки

Файл data.py - данные с адресом главной страницы, текстом ответов на вопросы на главной странице, набором данных для их использования параметризации в тесте, наборами данных для оформления заказа самоката и с данными титула страницы Дзена (для ее идентификации)

Файл base_page_locators.py - локаторы, применимые для любой страницы сервиса

Файл dzen_page_locators.py - локаторы, применимые для страницы Дзена

Файл main_page_locators.py - локаторы, применимые для главной страницы сервиса заказа самоката

Файл order_page_locators.py - локаторы, применимые для страницы оформления заказа самоката

Файл base_page.py - методы, применимые для любой страницы сервиса

Файл dzen_page.py - методы, применимые для любой для страницы Дзена

Файл main_page.py - методы, применимые для главной страницы сервиса заказа самоката

Файл order_page.py - методы, применимые для страницы оформления заказа самоката
